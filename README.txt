# 椅子取りゲーム・ランダム音楽プレイヤー

AndroidのChromeで使える簡易Webアプリです。

## 使い方
1. index.html をWeb上で公開する（GitHub Pages等）
2. Android Chromeで開く
3. YouTube URLを入力
4. 最短・最長再生秒数を設定
5. 「ゲーム開始」
6. アプリが設定範囲から毎回ランダムに停止時刻を決めます
7. 停止後は「再開」を先生が押します

## 注意
YouTubeの埋め込みプレイヤーを利用しています。YouTube側の仕様・動画の埋め込み可否・ブラウザの自動再生制限によって再生できない動画があります。
